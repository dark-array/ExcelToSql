# ExcelToSql

[English](#english) | [Español](#español)

ASP.NET Core 9 monolith that turns Excel/CSV into SQL scripts for PostgreSQL, SQL Server, MySQL, MariaDB, and Oracle.

---

## English

Web app: upload a spreadsheet, configure sheet by sheet (columns, types, cleanup), and generate `CREATE TABLE`, `INSERT`, or both.

Built for **local use**. The file is processed in the app itself; it is not sent to an external service.

### Why it exists

Loading an Excel file into a database usually means copying cells by hand or writing `INSERT` statements blindly. ExcelToSql infers types, sanitizes column names, cleans values, and emits the dialect of the engine you pick.

### Features

- Reads `.xlsx`, `.xls`, `.xlsm`, `.csv`, `.tsv`, and `.txt`
- One sheet at a time: pick, configure, save to a list (edit / delete). Avoids rendering 40 sheets at once
- Selectable columns, editable SQL names, adjustable types
- Type inference: integer, big integer, decimal, boolean, date, date/time, text, and long text
- Per-column cleanup: strip characters or whole tokens (e.g. `Activo[, ]`)
- Data preview that matches the current configuration (selected columns + cleanup applied)
- Identity / autoincrement on one column, **keeping the original IDs** from the file
- Skip blank rows, trim whitespace, first row as headers
- Copy the script or download a `.sql` file

### Requirements

- [.NET 9 SDK](https://dotnet.microsoft.com/download)
- Windows, Linux, or macOS
- A browser. You do not need SQL Server, Oracle, or any other engine installed to generate the script

### How to run

```bash
git clone <repo-url>
cd ExcelToSql
dotnet run
```

Open [http://localhost:5185](http://localhost:5185).

Sample CSV: `samples/clientes.csv`.

#### Publish a folder

```bash
dotnet publish -c Release -o ./publish
dotnet ./publish/ExcelToSql.dll --urls http://localhost:5185
```

Self-contained executable (no runtime install on the target machine):

```bash
dotnet publish -c Release -r win-x64 --self-contained true -o ./publish
```

Swap `win-x64` for `linux-x64` or `osx-arm64` as needed.

### Usage

1. **File.** Drag or pick an Excel/CSV (max 50 MB).
2. **Engine and output.** Choose PostgreSQL, SQL Server, MySQL, MariaDB, or Oracle. Table + inserts, `CREATE TABLE` only, or `INSERT` only.
3. **Global cleanup.** First row as headers, skip blank rows, trim whitespace. Click *Aplicar motor / encabezados* after changing engine or headers.
4. **Pick a sheet.** Select it in the combo and click *Cargar hoja*.
5. **Configure.** Table name, identity column, included columns, types, and *Quitar caracteres*. *Ver datos* shows the result with the current settings.
6. **Save to list.** Edit or remove items. SQL is generated only from the list (plus the sheet currently in the editor, if any).
7. **Generate SQL.** Copy or download the `.sql`.

The UI is in Spanish; the labels above match the buttons you will see.

#### Strip characters (per column)

The *Quitar caracteres* field works as follows:

| You type | Effect |
| --- | --- |
| `Activo[, ], Inactivo[, ]` | Removes `[`, `]`, `,`, and space. `Activo[ ]` becomes `Activo` |
| `"N/A"` | Removes the whole token `N/A` |
| `#$` | Removes those characters (when there is no `[...]`) |

Whatever is **inside** `[ ]` is stripped from the cell, including the brackets themselves. Words outside brackets or quotes are ignored. Use *Ver datos* to check before generating.

#### Identity / autoincrement

If you mark a column as identity:

- `CREATE TABLE` declares it as autoincrement / identity
- `INSERT` statements **include** that column with the Excel values
- SQL Server wraps the inserts with `SET IDENTITY_INSERT … ON/OFF`
- PostgreSQL and Oracle use `GENERATED BY DEFAULT AS IDENTITY` so the explicit value is accepted

### How SQL is generated

| Engine | Identifiers | Identity | Inserts |
| --- | --- | --- | --- |
| PostgreSQL | `"name"` | `GENERATED BY DEFAULT AS IDENTITY` | Multi-row |
| SQL Server | `[name]` | `IDENTITY(1,1)` + `IDENTITY_INSERT` | Multi-row |
| MySQL | `` `name` `` | `AUTO_INCREMENT` | Multi-row |
| MariaDB | `` `name` `` | `AUTO_INCREMENT` | Multi-row |
| Oracle | `"NAME"` | `GENERATED BY DEFAULT AS IDENTITY` | PL/SQL block |

Empty cells become `NULL`. Table/column names are sanitized (accents, spaces, duplicates, engine max length). You can still edit the SQL name by hand.

### Type inference

On non-empty cells of each column:

| If every value is… | Type |
| --- | --- |
| boolean (`si`/`no`, `true`/`false`, `1`/`0`, …) | Boolean |
| integer | Integer or big integer |
| numeric with decimals | Decimal (precision/scale measured) |
| dates without time | Date |
| dates with time | Date/time |
| anything else | Text (or long text past the length threshold) |

You can always change the type in the UI before generating.

### Limits

| Limit | Value |
| --- | --- |
| File size | 50 MB |
| Rows read per sheet | 100,000 |
| Form fields | 20,000 (needed when there are many columns) |
| Preview | first 500 rows (SQL uses every row that was read) |

The file is kept in a session temp store (2 hours idle). It does not persist after you close the app.

### Security

This is a local/desktop tool. It is not meant to be exposed on the internet: anyone who can reach the URL can upload files and generate SQL. If you host it, put it behind authentication and do not leave it open.

### Layout

```
ExcelToSql/
  Pages/              Razor Pages UI (upload → sheet list → SQL)
  Models/             Form options and spreadsheet model
  Services/           Excel/CSV reading, cleanup, dialects, SQL generation
  samples/            Sample CSV
  wwwroot/            Bootstrap 5, CSS, and UI JS
```

Relevant services:

| Class | Role |
| --- | --- |
| `SpreadsheetReader` | Reads Excel (ExcelDataReader) or CSV/TSV |
| `TypeInference` | Picks the logical type of each column |
| `DataCleaner` | Applies *Quitar caracteres* |
| `SqlDialectFactory` | PostgreSQL, SQL Server, MySQL, MariaDB, Oracle |
| `SqlScriptGenerator` | Builds `CREATE TABLE` + `INSERT` |
| `UploadedFileStore` | Per-session temp file |

One web app holds both the UI and the conversion logic.

## Español

Aplicación web monolito en ASP.NET Core 9 que convierte Excel o CSV en scripts SQL listos para ejecutar.

Subes un archivo, configuras hoja por hoja (columnas, tipos, limpieza) y generas `CREATE TABLE`, `INSERT` o ambos para **PostgreSQL**, **SQL Server**, **MySQL**, **MariaDB** u **Oracle**.

Pensada para **uso local**: el archivo se procesa en la propia app. No se envía a un servicio externo.

### Por qué existe

Cuando hay que cargar un Excel a una base de datos, el camino habitual es copiar celdas a mano o escribir el `INSERT` a ciegas. ExcelToSql infiere tipos, sanitiza nombres de columnas, limpia valores y genera el dialecto correcto del motor que elijas.

### Características

- Lectura de `.xlsx`, `.xls`, `.xlsm`, `.csv`, `.tsv` y `.txt`
- Trabajo hoja por hoja: eliges una, la configuras, la guardas en una lista (editar / eliminar). Evita renderizar 40 hojas a la vez
- Columnas seleccionables, nombre SQL editable y tipo ajustable
- Inferencia de tipos: entero, entero largo, decimal, booleano, fecha, fecha/hora, texto y texto largo
- Limpieza por columna: quitar caracteres o textos concretos (por ejemplo `Activo[, ]`)
- Vista previa de datos según la configuración actual (columnas marcadas + limpieza aplicada)
- Identity / autoincrement en una columna, **conservando los IDs originales** del archivo
- Omitir filas en blanco, recortar espacios, primera fila como encabezados
- Copiar el script al portapapeles o descargar un `.sql`

### Requisitos

- [.NET 9 SDK](https://dotnet.microsoft.com/download)
- Windows, Linux o macOS
- Un navegador. No hace falta SQL Server, Oracle ni otro motor instalado para generar el script

### Uso

1. **Archivo.** Arrastra o selecciona un Excel/CSV (máximo 50 MB).
2. **Motor y salida.** Elige PostgreSQL, SQL Server, MySQL, MariaDB u Oracle. Decide si quieres tabla + inserts, solo `CREATE TABLE` o solo `INSERT`.
3. **Limpieza global.** Primera fila como encabezados, omitir filas en blanco, recortar espacios. Pulsa *Aplicar motor / encabezados* si cambias motor o encabezados.
4. **Elegir hoja.** Selecciona una hoja del combo y pulsa *Cargar hoja*.
5. **Configurar.** Nombre de tabla, columna identity, columnas a incluir, tipos y *Quitar caracteres*. *Ver datos* muestra el resultado con la configuración actual.
6. **Guardar en lista.** Puedes editar o eliminar ítems. Solo se genera SQL de lo que está en la lista (más la hoja abierta en el editor, si la hay).
7. **Generar SQL.** Copia o descarga el `.sql`.

#### Quitar caracteres (por columna)

El campo *Quitar caracteres* interpreta el texto así:

| Escribes | Efecto |
| --- | --- |
| `Activo[, ], Inactivo[, ]` | Quita `[`, `]`, `,` y espacio. `Activo[ ]` queda `Activo` |
| `"N/A"` | Quita el texto completo `N/A` |
| `#$` | Quita esos caracteres (si no hay `[...]`) |

Lo que va **entre** `[ ]` se elimina de la celda, incluidos los propios corchetes. Palabras fuera de corchetes o comillas se ignoran. Usa *Ver datos* para comprobarlo antes de generar.

#### Identity / autoincrement

Si marcas una columna como identity:

- El `CREATE TABLE` la declara como autoincrement / identity
- Los `INSERT` **incluyen** esa columna con los valores del Excel
- En SQL Server se envuelve con `SET IDENTITY_INSERT … ON/OFF`
- En PostgreSQL y Oracle se usa `GENERATED BY DEFAULT AS IDENTITY` para poder insertar el valor explícito

### Cómo se genera el SQL

| Motor | Identificadores | Identity | Inserts |
| --- | --- | --- | --- |
| PostgreSQL | `"nombre"` | `GENERATED BY DEFAULT AS IDENTITY` | Multi-fila |
| SQL Server | `[nombre]` | `IDENTITY(1,1)` + `IDENTITY_INSERT` | Multi-fila |
| MySQL | `` `nombre` `` | `AUTO_INCREMENT` | Multi-fila |
| MariaDB | `` `nombre` `` | `AUTO_INCREMENT` | Multi-fila |
| Oracle | `"NOMBRE"` | `GENERATED BY DEFAULT AS IDENTITY` | Bloque PL/SQL |

Celdas vacías se exportan como `NULL`. Los nombres de tabla/columna se sanitizan (acentos, espacios, duplicados, longitud máxima del motor). Puedes editar el nombre SQL a mano.

### Inferencia de tipos

Sobre las celdas no vacías de cada columna:

| Si todos los valores… | Tipo |
| --- | --- |
| son booleanos (`si`/`no`, `true`/`false`, `1`/`0`, …) | Booleano |
| son enteros | Entero o entero largo |
| son numéricos con decimales | Decimal (precisión/escala medidas) |
| son fechas sin hora | Fecha |
| son fechas con hora | Fecha/hora |
| cualquier otra cosa | Texto (o texto largo si supera el umbral de longitud) |

Siempre puedes cambiar el tipo en la UI antes de generar.
